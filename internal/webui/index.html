ТРАФИК

Что направлять через VPN

Оставьте поле пустым для всей сети. Укажите IP через запятую или с новой строки, чтобы применять режим только к этим устройствам. Для надёжной работы закрепите IP за устройством в настройках DHCP роутера.

Правила маршрутизации

Импортируйте ссылку Happ или Common для правил геоблока. После импорта режим «Правила Happ Routing» включится автоматически; другие режимы можно выбрать выше.
